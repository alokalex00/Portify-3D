
# My Portfolio

## Run locally

1. Install Node.js.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Build for deployment

Run `npm run build`.

The production files will be created in the `dist` folder.

## Deploy

Upload this project to GitHub and import the repository into Vercel. Vercel should detect Vite automatically.
